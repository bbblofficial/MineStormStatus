# MineStormStatus

Paper/Purpur plugin (Java 21): `/status busy|idle|away|clear`, mention alerts, auto-AFK and a persistent action bar HUD.

Build locally: `mvn clean package` -> `target/MineStormStatus-1.0.0.jar`.
On GitHub, every push runs `.github/workflows/build.yml`; download the jar from the run's **Artifacts** section.
